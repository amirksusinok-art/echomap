# EchoMap — сканер камеры

[Открыть сайт](https://amirksusinok-art.github.io/echomap/)

EchoMap обрабатывает кадры камеры локально и показывает точки на контрастных деталях. Можно изменить плотность точек, выбрать основную или фронтальную камеру, скрыть фон и сохранить PNG. Точки находятся в плоскости изображения. Расстояние и трёхмерная геометрия не вычисляются.

## Запуск

Установите Node.js 22.18+ и выполните:

```sh
npm ci
npm run dev
```

Для камеры откройте localhost или HTTPS. Для выпуска соберите проект командой npm run build и синхронизируйте содержимое dist с каталогом docs, сохраняя docs/.nojekyll. GitHub Pages публикует каталог docs из ветки main.

## Проверка

```sh
npm test
npm run build
npx playwright test
```

Браузерные тесты по умолчанию используют установленный Microsoft Edge. Контролируемый видеопоток используется только в тестах.
