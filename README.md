# EchoMap v1.1

Экспериментальный акустический сканер на React, TypeScript, Tailwind, Web Audio API, AudioWorklet и Canvas.

## Запуск

Установите Node.js 22.18+ и выполните в папке проекта:

```sh
npm ci
npm run dev
```

Откройте адрес Vite в браузере. Готовая статическая сборка находится в dist. Для её локального запуска используйте npm run preview. Для телефона разместите содержимое dist на статическом хостинге с HTTPS. Микрофону нужен защищённый контекст, поэтому обычный HTTP по локальному IP не подходит.

## Измерение

Пользуйтесь встроенным динамиком на низкой системной громкости. Отключите наушники и Bluetooth. Перед серией выполняются три калибровочных импульса. Quick Scan использует ещё три импульса, Deep Scan — восемь. В 360° Scan медленно поворачивайтесь и задерживайтесь на каждой отметке. При отсутствии показаний датчика подтвердите положения вручную. Частичный круг можно сохранить.

Согласованный фильтр ищет опорный сигнал и повторяемые пики. Если опора стабильна, половина избыточного пути при скорости звука 343 м/с даёт ориентировочную оценку расстояния. Раздельное положение динамика и микрофона, встроенная обработка звука, многолучёвость и температура влияют на результат. При нестабильной опоре показываются относительные задержки, если пики повторяются. Индекс качества учитывает выделение пика над фоном, качество опоры, повторяемость и калибровку. Индекс не является вероятностью правильного измерения. Угол в 360° относится к сектору положения телефона.

Аудиоданные обрабатываются в браузере, последний фрагмент хранится в памяти для лаборатории. В локальное хранилище записываются настройки и до 60 замеров без аудиозаписи.

## Проверка

```sh
npm test
npm run build
npx playwright test
```

Браузерные тесты по умолчанию используют Microsoft Edge. Для установленного Chrome задайте ECHOMAP_BROWSER=chrome. Тесты DSP используют известные задержки, шум и перегрузку. Браузерные тесты используют контролируемую тишину для проверки цепочки AudioWorklet и остановки дорожки. Для проверки физической акустики прогоните калибровку, Quick Scan и ручной 360° на каждом целевом устройстве, затем сравните повторные замеры при неизменной позиции телефона.
